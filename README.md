# Samsa Run

Браузерная игра для изучения английских слов: самса бежит по трём дорожкам ташкентского парка или музея Узбекистана, собирает переводы и обходит препятствия. Работает на компьютере и смартфоне, использует WebGL и не требует регистрации или сервера приложения.

[Играть](https://hydrock.github.io/Samsa-Language-Run/) · [Репозиторий](https://github.com/Hydrock/Samsa-Language-Run)

На больших экранах игровая область ограничена 1280×900 и расположена по центру на узорчатом фоне. На смартфонах она занимает доступный экран. Разрешение WebGL ограничено 1280×900 (900×1280 в портретной ориентации) для снижения нагрузки.

## Как играть

Сверху показано русское слово. На дорожках по одному появляются английские варианты. Правильный перевод даёт **+1**, неправильный перевод или столкновение — **−1**. Слова можно пропускать или перепрыгивать без штрафа. Дорожный блок и конус перепрыгиваются; встречных персонажей нужно обходить.

Забег заканчивается, когда счёт становится отрицательным. При нуле можно продолжать. Экран результата показывает максимум за забег и рекорд. Рекорд и настройки сохраняются в localStorage браузера, отдельно на каждом устройстве и адресе сайта.

| Компьютер | Действие |
|---|---|
| ← / → или A / D | Сменить дорожку |
| Пробел / ↑ / W | Прыгнуть |
| Escape | Пауза / продолжение |

На смартфоне доступны свайпы влево, вправо и вверх, а также экранные кнопки. В горизонтальном режиме стрелки расположены слева, прыжок справа.

В настройках можно переключить локацию «Ташкентский парк / Музей Узбекистана» без сброса забега и выбрать один из трёх режимов сложности и пяти музыкальных композиций, отключить музыку или весь звук, включить транскрипции обоих языков. Открытие настроек и скрытие вкладки останавливают забег. Каждую минуту игрового времени сменяются утро, день, вечер и ночь.

По умолчанию открывается музей; ранее выбранная локация сохраняется. В музее вдоль дорожек стоят пять видов рисованных экспонатов: керамика, сюзане, резная колонна, чапан с тюбетейкой и дутар. Встречаются экскурсовод, турист с камерой и смотритель; ограждение и ящик можно перепрыгивать. Внутри сохраняется тёплое освещение, а парк меняется со временем суток. Выбранная локация сохраняется между посещениями.

### Обучение

В словаре **1000 пар**, по 100 на каждый вес от 1 до 10. Каждые 5 очков открывают следующий уровень: 0–4 → 1, 5–9 → 2, …, 40–44 → 9, 45+ → 10. При 50 очках максимальный уровень уже открыт. Потеря очков через границу уровня сразу упрощает задание.

75% новых заданий выбираются из текущего уровня, 25% — из предыдущего для повторения. На первом уровне доступны только слова веса 1. Шкала авторская, не официальный CEFR-рейтинг. Новые транскрипции сгенерированы автоматически и нуждаются в редакторской проверке.

Вероятность правильного варианта растёт после появления неверных: **22% → 41% → 60% → 79% → 100%**. Она сбрасывается после появления верного варианта, даже если игрок его пропустил. Это вероятность для последовательности слов, а не гарантия одного правильного слова на трёх дорожках одновременно.

## Локальный запуск

Нужен Node.js 20 или новее; в CI используется Node.js 22. Установка npm-зависимостей и сборка не нужны.

```bash
npm start
```

Откройте http://localhost:8080/. Сервер слушает только `127.0.0.1`, поэтому этот адрес не откроет игру с другого телефона в сети. Для проверки на телефоне используйте опубликованный сайт.

Проверки:

```bash
npm test
node --check src/game.js
```

Для запуска прямо из PowerShell в UNC-папке WSL можно использовать `node scripts/serve.js` и `node --test tests/logic.test.js`: npm через CMD может потерять текущую UNC-папку. Альтернатива — терминал Ubuntu с установленным Node.js.

Открытие `index.html` через `file://` не поддерживается: ES-модулям нужен HTTP. Требуется браузер с WebGL 2. Музыка начинает работать после действия пользователя.

## Деплой на GitHub Pages

Проект уже содержит [.github/workflows/pages.yml](.github/workflows/pages.yml). Итоговый адрес: https://hydrock.github.io/Samsa-Language-Run/.

1. Откройте [Settings → Pages](https://github.com/Hydrock/Samsa-Language-Run/settings/pages).
2. В **Build and deployment → Source** выберите **GitHub Actions**. Создавать ещё один workflow по шаблону не нужно.
3. Закоммитьте и отправьте файлы проекта в `main` или `master`.
4. В [Actions](https://github.com/Hydrock/Samsa-Language-Run/actions) дождитесь зелёного результата **Deploy GitHub Pages**.
5. Откройте адрес игры. Если отображается старая версия, обновите страницу с очисткой кеша.

Пример для существующей локальной копии в Ubuntu / WSL:

```bash
cd /home/smitevils/projects/Samsa-Language-Run
git status
git remote -v
git add README.md AGENTS.md docs .github index.html package.json scripts src tests vendor
git diff --cached --stat
git commit -m "Update Samsa Run"
git push origin main
```

Проверьте `git remote -v`: origin должен указывать на `Hydrock/Samsa-Language-Run`. Если текущая ветка другая, сначала перенесите изменения в основную ветку обычным для проекта способом. Не используйте принудительный push для обхода конфликтов.

Каждый push в `main` или `master` запускает публикацию автоматически. Ручной запуск: **Actions → Deploy GitHub Pages → Run workflow**. Workflow запускает тесты, копирует `index.html`, `src/` и `vendor/` в `_site`, загружает артефакт и публикует его. Node.js используется для тестов; Python и eSpeak на хостинге не нужны.

Подробнее: [развёртывание и устранение ошибок](docs/DEPLOYMENT.md). Настройка источника публикации: [GitHub Docs](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Технические особенности и работа агентов

Игра — статический сайт на HTML/CSS и JavaScript ES-модулях. Three.js 0.170.0 хранится локально в `vendor/`; CDN, API-ключи и backend не используются. Парк сочетает простую геометрию и прозрачные PNG-спрайты, звук синтезируется Web Audio.

- [Архитектура и игровые инварианты](docs/ARCHITECTURE.md)
- [Инструкции для программирующих агентов](AGENTS.md)
- [Запуск, деплой и диагностика](docs/DEPLOYMENT.md)

Все пути ресурсов относительные, включая публикацию в подпапке репозитория. Изображения должны храниться в `src/assets/`, а не ссылаться на локальные пути компьютера. Лицензия Three.js сохранена в `vendor/`. Иллюстрации созданы на основе предоставленных пользователем референсов; лицензия Three.js не распространяется автоматически на иллюстрации или весь проект.

Музыка «Парк» — `src/assets/main-theme.mp3`, предоставленная пользователем (исходное имя: roblox-minecraft-fortnite-video-game-music-564544-compress.mp3). MP3 загружается только при воспроизведении выбранной композиции. Остальные три мелодии синтезируются локально и не требуют загрузки аудиофайлов. Сохранённый выбор музыки учитывается.

На паузе и после проигрыша доступна прокручиваемая история текущего забега: собранные слова, правильность ответа, верный перевод, выбранный ошибочный вариант, транскрипции и столкновения. Новые события сверху. Пропущенные слова не записываются. Новый забег очищает историю; она не сохраняется после перезагрузки.

Композиция «Фолк» использует предоставленный файл folk-2mb.mp3. Автоматическая смена музыки (по умолчанию выключена) воспроизводит список по кругу с выбранной композиции: Парк → Фолк → Утро в Ташкенте → Вечер на Чорсу → Шёлковый путь. MP3 играют до конца, синтезированные мелодии — четыре музыкальные фразы. Загружается только текущий аудиофайл.

## Новые локации

Карты описаны в `src/maps/*.json`. В каждой по пять видов бокового декора с настраиваемой плотностью слева и справа и по пять видов препятствий (два барьера и три встречных персонажа). Для новой карты скопируйте JSON и добавьте файл в `src/maps/index.json`; селектор обновится автоматически. Подробности и примеры: [Создание карты](docs/MAPS.md).

Громкость музыки регулируется ползунком 0–100% рядом с выбором композиции и сохраняется. По умолчанию 30%; громкость игровых эффектов не меняется.

Локация **«Рынок Чорсу»** доступна в настройках: пять видов прилавков (фрукты, пряности, лепёшки, мясо, молочные продукты), покупательница, мясник и пекарь. Ящики с фруктами и мешки со специями можно перепрыгивать. Используются предоставленные пользователем атласы bazar.png и chorsu-people.png. По бокам размещены по 12 прилавков вместо стандартных 18; число вариантов препятствий соответствует остальным картам.

На дальнем плане парка находятся стилизованная ташкентская телебашня и купол; на рынке — низкополигональный павильон Чорсу с широким бирюзовым куполом. Фоновые модели описаны в JSON и не влияют на препятствия.

По умолчанию выбрана композиция «Фолк». Ранее сохранённый выбор музыки сохраняется.

Отдельный ползунок «Громкость звуков» регулирует прыжки, смену дорожки и сигналы ответа от 0 до 100%, независимо от музыки. Значение сохраняется; по умолчанию 100% прежней громкости эффектов.

После проигрыша кнопка «Случайная локация» под «Бежать снова» сразу запускает новый забег на случайной карте из полного списка (текущая также может выпасть). Выбор карты сохраняется.

Кнопка «Поделиться игрой» на экране результата открывает системное меню отправки с результатом забега и публичной ссылкой. Если меню недоступно, копирует ссылку; если буфер обмена запрещён, показывает поле для ручного копирования. Отмена отправки ничего не копирует.

Карта «Махалля»: старые дома, ворота с виноградом, припаркованные автомобили, арыки и дальняя пергола. Встречные — ребёнок, пожилая жительница и кот; голубя и тележку с арбузами можно перепрыгивать. Атлас mahalla.png предоставлен пользователем, дома подготовлены с прозрачностью через ImageGen по houses.png. Карта использует общий бюджет: 5 вариантов декора и 2 + 3 препятствия.

На дальнем плане махалли — шесть низкополигональных домов и небольшая стилизованная мечеть с бирюзовым куполом и минаретом. Модели неподвижны и описаны в environment карты.


Произношение: src/speech.js использует SpeechSynthesis браузера, предпочитая локальный голос соответствующего языка. После правильного ответа читает английское слово (не строку IPA). pronunciation выключено по умолчанию, speechVolume — 0.8; оба значения сохраняются. Переключатель отключает автоматическое чтение, кнопки ▶ в истории позволяют слушать русский оригинал, верный перевод и ошибочный выбор вручную. Общий mute и нулевая громкость отключают также ручное чтение. Новая фраза заменяет предыдущую; пауза, настройки, рестарт и скрытие вкладки отменяют речь. При отсутствии API элементы отключены. Наличие голосов, качество произношения и ограничения запуска зависят от браузера и ОС; на физических iOS/Android необходима отдельная проверка. API: https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance
