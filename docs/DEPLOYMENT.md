# Развёртывание и диагностика

## Среды

| Среда | Адрес / команда |
|---|---|
| Локальная разработка | `npm start`, http://localhost:8080/ |
| Тесты | `npm test` |
| GitHub Pages | https://hydrock.github.io/Samsa-Language-Run/ |

Сайт не требует серверной логики. Нужны `index.html`, весь `src/` и `vendor/`. Генерация словаря — отдельная операция разработки, не этап деплоя.

## Первая публикация

1. В репозитории откройте **Settings → Pages** и установите **Source: GitHub Actions**.
2. Убедитесь, что в основной ветке есть `.github/workflows/pages.yml`, `package.json`, `tests/`, `index.html`, `src/`, `vendor/`.
3. Отправьте коммит в `main` или `master`.
4. Откройте **Actions → Deploy GitHub Pages** и проверьте все шаги.
5. Откройте опубликованный адрес с завершающим `/`.

Workflow работает на Ubuntu, использует Node.js 22 и права `contents: read`, `pages: write`, `id-token: write`. Окружение публикации — `github-pages`. Параллельный новый деплой отменяет предыдущий незавершённый запуск. Дополнительные секреты не нужны.

В артефакт не включаются README, документация, тесты и скрипты разработки. Если новые ресурсы размещаются за пределами `src`/`vendor`, нужно явно изменить шаг копирования. Рекомендуется хранить игровые ресурсы внутри `src/assets`.

## Последующие обновления

Коммит и push в основную ветку автоматически обновляют сайт. Можно вручную запустить workflow на основной ветке через **Run workflow**. Не создавайте параллельно второй Pages-workflow или отдельную ветку `gh-pages` без необходимости.

Для отката отмените проблемный коммит через `git revert`, проверьте результат и отправьте новый коммит: обычный workflow опубликует его.

## Диагностика

| Симптом | Проверка |
|---|---|
| 404 на сайте | Source = GitHub Actions, успешный последний деплой, полный путь `/Samsa-Language-Run/` |
| Workflow отсутствует | Файл workflow закоммичен в основную ветку; Actions разрешены для репозитория |
| Ошибка `npm test` | Откройте упавший шаг и выполните тесты локально |
| Ошибка Configure Pages | Проверьте Settings → Pages и права настройки репозитория |
| Ошибка Deploy | Проверьте разрешения workflow и правила окружения `github-pages` |
| Картинки не загружаются | Файлы закоммичены; регистр имён совпадает; пути относительные |
| Старая версия | Дождитесь завершения публикации и обновите страницу без кеша |
| SSH: Permission denied (publickey) | Настройте SSH для GitHub либо используйте HTTPS с подходящей аутентификацией |
| Git просит автора | Настройте `git config user.name` и `git config user.email` |
| Телефон не открывает localhost | Localhost телефона указывает на сам телефон; локальный сервер привязан к loopback компьютера |
| Нет музыки до старта | Web Audio активируется после пользовательского нажатия |
| Рекорд не перенёсся | localStorage разделён по origin, браузерам и устройствам |

Не используйте `git push --force` для исправления обычной ошибки отправки. Не размещайте токены в файлах проекта.

## Проверка публикации

Проверьте старт, оба направления смены дорожки, прыжок, слова, препятствия, звук, настройки, паузу и повторный запуск. На смартфоне проверьте обе ориентации и прокрутку настроек. Убедитесь, что в консоли нет ошибок загрузки PNG/модулей.
